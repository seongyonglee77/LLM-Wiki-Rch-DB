# Citation Gaps

Use this file for citation needs that are not yet resolved by the database.

## Rules

- Check the configured database search paths first: `indexes/`, `wiki/`, `cards/`, and `sources/`.
- Use external search only when explicitly requested.
- Do not add a source to `references.bib` by hand. The bibliography is generated.
- Regenerate project bibliography output with `export_project_bib.py`.
- Once a gap is resolved by a database record, move the decision into `literature-evidence.json`.
