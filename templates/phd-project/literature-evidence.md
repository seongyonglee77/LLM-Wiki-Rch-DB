# Literature Evidence

This is a human-readable generated view of `literature-evidence.json`, normally produced by `project_literature.py`.

Do not hand-edit this Markdown file for durable changes. The canonical project literature record is JSON with this schema:

```json
{
  "schema_version": 1,
  "records": []
}
```

Each record should contain:

- `record_id`
- `card_path`
- `citation_key`
- `decision` (`candidate`, `selected`, or `excluded`; use `Undecided` when the decision is not yet known)
- `decision_reason`
- `argument_role`
- `evidence`, with entries containing `source_path`, `quote`, `locator`, `verification`, and `interpretation`
- `unknowns`
- `reference`

Evidence must be verified before it is used in a project argument. Verification does not authorize autonomous source selection; selection decisions remain explicit project decisions in the canonical JSON.
