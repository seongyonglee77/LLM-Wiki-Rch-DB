# Project Writing Contract

This project consumes the shared llm-wiki root at:

```text
{{LLM_WIKI_ROOT}}
```

- Shared cards and root `refs.bib` are canonical inputs.
- This project's `references.bib` is generated output and must not be manually edited.
- Drafts must use Pandoc citation keys in `[@citation_key]` form.
- Web-found candidates outside the registry go to `citation-gaps.md`.
- Run citation verification before reporting a draft as complete.
